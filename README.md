I work where **optimization meets software**: vehicle routing, rolling-horizon planning, and decision-support tools that teams actually use. I like taking a vague operational problem, writing it down as a model, and shipping the code that turns the model's answers into decisions.

On the side I build native iOS apps and small graphics experiments in WebGL.
